# Проект по инженерии данных: Нормализация данных доставок

## Нормализованная схема данных

### Таблицы в 3НФ:
1. **users** - Пользователи
2. **stores** - Магазины  
3. **items** - Товары
4. **drivers** - Курьеры
5. **orders** - Заказы
6. **order_items** - Позиции заказов
7. **delivery_history** - История доставок

### Витрины данных:
1. **datamart.orders_daily** - Ежедневная статистика по заказам
2. **datamart.product_sales_daily** - Ежедневная статистика по товарам
